## Current implementation

The current CMS page is `/locations`, with HTML, CSS and JavaScript preserved in Page Studio and exported in `docs/cms-pages/velori-pages.json`. Its currently authored content follows.

Start with a place or topic
Use the search below to open VELORI’s existing search experience. Results depend on what members have shared and what your account can access.

What a result means
A name in a caption or profile is member-provided information. This is not a verified place database, check-in system or nearby-location map.

Share location thoughtfully
Avoid posting a home address, daily routine or another person’s live location without permission. Review a post’s audience before sharing personal details.

## Expanded authored requirements and content

## 3.9 VELORI Locations — `/locations`

**Hero:** VELORI Across Communities.

### Introductory copy

"VELORI is a digital platform designed for people to connect across places and communities. This page helps users understand regional availability, supported languages and verified contact locations."

### Content

Show:
- Supported regions based on actual service availability.
- Localized language availability.
- Service accessibility and availability notices.
- Official office locations only when verified.
- Contact options.
- Regional policy links when needed.

Never invent company offices.

### UI

An animated globe or regional illustration, region selectors, language controls and regional information cards.

Any physical map must reflect actual verified addresses or coverage data.
