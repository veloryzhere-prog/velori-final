# VELORI product overview

> Implementation status: the current public documentation release is deployed as version 20. The expanded workflow requirements below are not all implemented. New relational tables are a review-only proposal; no migration has been applied. This document is not evidence of a deployed API, legal approval, live vacancy, delivered email or translated platform.

VELORI is the existing React/Vite/TypeScript social platform backed by Supabase Auth, Postgres, Storage and Edge Functions. It contains posts, reels, stories, profiles, connections, private chats, groups, notifications, creator tools and a permission-checked administrator console. VELORYZ is the parent brand.

The documentation release adds 23 CMS-authored pages and source-preserving administration. It does not by itself create a jobs marketplace, support desk, developer OAuth server or AI assistant. Product availability must be checked against the implementation-status record, deployed schema and tested handlers.
