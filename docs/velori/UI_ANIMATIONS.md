## Multilingual interface

Smooth language change without flashing, broken layout or navigation reset.

## Motion quality requirements

- No perpetual high-intensity movement around reading text.
- No unnecessary animation libraries.
- No remote animation assets unless approved.
- Prevent layout shifts.
- Use performant transform and opacity transitions where possible.
- Ensure animations work in actual Chrome, Firefox, Edge and supported mobile browsers.
- Do not claim success solely from an integrated preview.

---

## Current tested behavior

The global Full/Gentle/Off/Device-setting control drives iframe roots. Full enables paper/orbit/logo loops; Gentle avoids continuous decorative movement; Off disables decorative animation. Hidden and off-screen scenes pause. Help FAQ, the emoji picker and document navigation were inspected in the actual browser. Do not claim Firefox, Safari, every device or independent accessibility certification from one browser pass.

## Reading controls

Keep content immediately readable; do not wait for a cover animation before rendering text. Preserve the URL and history. The current chapter links scroll the parent view with focus restoration and no animation in Off mode.
